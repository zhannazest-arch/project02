🔌 MCP & Subagent Requirements
В проекте:
каждая роль (backend developer и frontend developer) должна использовать минимум 1 MCP или sub-agent
минимум 2 MCP / sub-agent на команду( если вас 2 человека )
AI должен реально использовать внешний контекст
Примеры MCP / sub-agent:
Context7 MCP
Playwright MCP
Pupeteer MCP
Code-analysis sub-agent
